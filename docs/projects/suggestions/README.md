# Suggestions

Đề xuất đã được phân loại là thuộc riêng repo này.

- Mỗi đề xuất một file `MM-YYYY/SUGGESTION-NNN-slug.md`, dùng [mẫu suggestion](../../templates/suggestion-template.md).
- Góp ý gửi qua GitHub chỉ là đầu vào; phân loại xong mới tạo hồ sơ.
- Đề xuất ảnh hưởng nhiều repo thuộc repo gốc (IDEA) — ghi link sang đó.
