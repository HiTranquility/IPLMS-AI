# issues

Việc triển khai; mỗi ISSUE một thư mục: `issue.md` + `phase/ review/ handoff/ evidence/`.

- Mẫu: [`issue-template.md`](../../templates/issue-template.md)
- Đường dẫn: `issues/MM-YYYY/ISSUE-NNN-slug/issue.md`
- Giao việc và theo dõi ở [`BOARD.md`](../BOARD.md); bố cục chung ở [`projects/README.md`](../README.md).
