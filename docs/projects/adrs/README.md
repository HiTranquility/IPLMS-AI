# Architecture Decision Records

Use this folder for decisions that are local to this repository.

- One ADR is one Markdown file: NNNN-short-decision-name.md.
- Use the ADR template in ../../templates/adr-template.md.
- Cross-module decisions, including repository boundaries and shared contracts, belong in the root IPLMS ADR collection.
- Do not create an ADR just to document an implementation detail; use a guide or issue instead.
