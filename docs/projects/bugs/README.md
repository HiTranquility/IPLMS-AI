# bugs

- Mẫu: [`bug-template.md`](../../templates/bug-template.md)
- Đường dẫn: `bugs/bug-NNN-slug/bug.md`
- Giao việc và theo dõi ở [`BOARD.md`](../BOARD.md); bố cục chung ở [`projects/README.md`](../README.md).
